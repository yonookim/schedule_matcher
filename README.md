# 아낮밤 — Schedule Matcher

여러 사람의 일정을 쉽고 빠르게 조율할 수 있는 웹 기반 스케줄 매칭 도구입니다.

🔗 서비스 링크  
https://yonookim.github.io/schedule_matcher

## 주요 기능

- 2~8명까지 함께 일정 조율 가능
- 정해진 기간 안에서 **불가능한 시간대**를 선택
- 아침 / 낮 / 밤 단위로 세분화하여 입력 가능
- 모두가 가능한 후보 일정을 자동으로 안내
- 후보 일정 중 선호 날짜를 투표하여 최종 약속 날짜 결정


## 사용 방법

### 1. 투표 만들기

1. 프로젝트 이름, 참여 인원 수, 일정 조율 기간을 설정합니다.
2. 본인 닉네임을 등록합니다.
3. 본인이 **불가능한 시간대**를 선택합니다.
   - 아침, 낮, 밤으로 나누어 선택할 수 있습니다.
   - 날짜 숫자를 누르면 해당 날짜의 아침/낮/밤이 한 번에 선택됩니다.
4. 그룹 링크를 복사해 참여자들에게 공유합니다.

### 2. 참여하기

1. 공유받은 링크로 접속합니다.
2. 본인 닉네임을 등록합니다.
3. 본인이 **불가능한 시간대**를 선택합니다.
4. 모든 참여자가 제출하면, 모두가 가능한 후보 일정이 표시됩니다.
5. 후보 일정 중 선호하는 날짜를 투표합니다.
6. 투표 결과를 확인해 최종 약속 날짜를 정합니다.


면접 스터디, 팀 프로젝트, 여행 일정, 모임 날짜처럼  
여러 사람이 함께 가능한 시간을 찾아야 할 때 사용할 수 있습니다.
